# Document and presentation standards

## Shared source discipline

- Build from approved canonical results, figure-ready datasets, and chart map.
- Keep claim-to-source references and caveats with each section/slide.
- Do not manually retype important values.
- Route numerical or definition corrections back to canonical results, then regenerate dependents.

## Reports and PDFs

- Lead with the decision and answer; separate evidence, implication, recommendation, risk, and methods.
- Use consistent headings, typography, spacing, margins, tables, captions, page numbers, headers/footers, cross-references, sources, and appendices.
- Place figures beside the claims they support.
- Include methodology/model documentation and glossary only where useful to the audience.
- Render every page and inspect overflow, clipping, broken page breaks, orphan headings, tables, low-resolution figures, bookmarks, links, and accessibility.

## Presentations

- Use one message per slide and a coherent situation -> evidence -> implication -> recommendation -> risk -> next-action arc.
- Prefer charts and concise tables to prose walls.
- Put units, dates, populations, and caveats on the slide.
- Include technical appendix slides for methods and validation when the audience needs assurance.
- Render and inspect all slides for alignment, contrast, crop, overflow, legibility, and speaker-note/source consistency.

## Reconciliation gate

Compare every headline value, chart, table, rounding rule, definition, recommendation, and caveat against the canonical register. Record artifact version, canonical version, reviewer, defect, repair, and retest result.
