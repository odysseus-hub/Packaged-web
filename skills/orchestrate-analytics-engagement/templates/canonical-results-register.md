# Canonical results register

Use one stable ID per approved value, table, forecast, prediction set, figure-ready dataset, or definition.

| ID | Type | Name/definition | Value/artifact | Unit/denominator | Population/date range | Source data + checksum | Code/notebook location | Uncertainty | Caveats | Version | Owner | Reviewer | Status |
|---|---|---|---|---|---|---|---|---|---|---:|---|---|---|

Allowed status: `draft`, `provisional`, `validated`, `rejected`, `superseded`, `blocked`.
